# plouf

Site pour faire plouf – built with a modern animation stack.

## Tech Stack

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS** – utility-first styling
- **Framer Motion** – hero entrance animations
- **GSAP ScrollTrigger** – scroll-driven card animations
- **React Three Fiber** + **@react-three/drei** – 3D scene in the hero

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.
